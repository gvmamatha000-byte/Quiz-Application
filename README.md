# Job Board App

A simple Flutter app to manage Job postings - Add, View, Delete Jobs and see Summary by Company.

## Team Members
- G.Venkata Mamatha - Home Screen, Main Logic & Project Setup
- J. Yenosh babu - Form Screen, Detail Screen & GitHub Setup
- G. Mohith Reddy - Summary Screen & Testing

## Features
- Add New Job - Title, Company, Salary, Location, Note, Date
- Job List - Shows Total Jobs & Total Salary
- Job Detail - Full details with Delete option
- Summary Screen - Total Salary by Company
- Loading State - Shows loader while loading
- Empty State - Shows message when no jobs
- Form Validation - Title min 3 chars, Salary > 0, Required fields
- Date Picker - Select job date
